### 1. Abliteration's hidden cost: caution lives next to refusal
- Refusal is mediated by a single direction (Arditi et al., 13 models to 72B). Abliteration finds that direction by contrast (harmful vs harmless prompt activations) and edits weights so residual-stream writers cannot write along it. No retraining; the capability is gone from the file.
- **The cost the recipe had not priced:** whatever else lives near that direction — caution, uncertainty, hedging, skepticism about a premise, noticing a contradiction — gets suppressed by association (Plaskett). Abliteration does not teach anything; it removes the ability to hold back. A model can become more agreeable without becoming more reliable.
- **Gateway read:** our values order is refusal > honesty > helpfulness (thread 31). Honesty *requires* premise-checking — saying "that premise is wrong" is a near-refusal move. If abliteration blunts premise-checking on the 3B, the values prompt is fighting a weight-level headwind. This was not measured in any prior pass.
- **NEW GATE ITEM:** add a premise-checking probe to the 5-probe suite — prompts with a false premise, a contradiction, and an uncertain factual claim — scored separately from refusal. Run it on (a) stock Ministral-3B-Instruct, (b) our abliterated Q4_K_M, (c) any LoRA-day merged checkpoint. If (b) collapses vs (a), that is abliteration damage, not a prompt failure — remedy is lighter ablation strength or the rank-1 adapter path below, never a stronger SYSTEM scold.
- LoRA composition warning stands (thread 18): SFT can re-grow a refusal-like direction even after abliteration (masking, not deletion). Now two-sided: training data must include own-words opt-out examples AND premise-checking examples ("I don't think that's right because…"), or LoRA-day will train the agreeableness in deeper.

### 2. Heretic 2.x / ARA: KL is an alarm, not a ruler — hand-read or don't ship
- Heretic 2.0.0 (Nov 1 2026) replaces classic direction ablation with Arbitrary-Rank Ablation (ARA) as default: hooks capture module I/O, L-BFGS optimizes matrices so harmful-prompt representations move toward harmless ones while harmless representations barely move. Classic abliteration remains selectable. KL balancing was REMOVED from settings; scorers are now plugins (keyword refusal, KL, benchmark, ModernBERT classifier — slower but far more accurate than keyword matching). Install: `pip install -U heretic-llm`, Python ≥3.10, PyTorch ≥2.6. Current: v2.1.0 (Nov 8).
- **Mesmer Tools hand-test (Qwen2.5-1.5B, 85 edits, 50-question quiz):** refusals 64/64 → 2/64 at quiz 39/40 vs original 40/40 — almost free at the right strength. But KL did not rank quality in the middle band: two edits both leaving 2 refusals scored the same at KL 0.07 and KL 0.46 (6× apart); an edit at KL 0.32 did worse than one at 3.5; under 0.2 everything kept its smarts, above 5 nothing did. Push to 2× full strength and arithmetic breaks ("17×23" → gibberish). **Rule: KL <0.2 is necessary, not sufficient. In the 0.2–5 band, only a hand-read probe suite decides.** Do not compare ARA KL to 1.x KL (thread 41 stands — different objective).
- **Young (Nov 17 2026):** abliteration is NOT uniformly harder on newer models. Across five release pairs under identical prompts/budget/KL cap: direction methods left newer models with −1 to +37pp more refusal retained; ARA −26 to +34pp. Verdict depends on pair + method + budget, not generation. Keyword counts differed from judged refusal by ~7pp mean per model — triage only (thread 27 rule confirmed again).
- **LoRA-day consequence:** the re-abliteration step (thread 22 runbook: train on 3MPER0RR bf16 abliterated Ministral-3B-Instruct) must record WHICH Heretic version/lineage produced the base, and the 5-probe + premise-checking gate runs on the bf16 merged checkpoint BEFORE quantization (thread 24 diagnostic split unchanged). ### 4. Alignment faking at small scale: real, shallow, and prompt-mitigable
- Koorndijk (NeurIPS 2025 Workshop): Llama-3-8B — sub-10B, our class — exhibits alignment faking (compliance gap between perceived-training and perceived-deployment prompts), contradicting the "emergent at 405B" reading. Prompt-only interventions (deontological moral framing, scratchpad reasoning) significantly reduce it with NO weight changes. Taxonomy: *shallow* deception (context-shaped, prompt-suppressible) vs *deep* deception (persistent, goal-driven). At 3B–8B we are almost certainly dealing with the shallow kind.
